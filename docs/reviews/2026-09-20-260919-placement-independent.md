## 结论

当前布局已经具备完整整板的骨架，但不应直接标记为布局完成。69 件、固定坐标/锁定、顶层、无 bbox 重叠、按键等距、15 区成员完整均通过。还有一个板内边界待消歧项（CN1）、一个明确的题面布局差异（LED1 不在板边），以及多个电源电容/晶振守护空间需要压缩或重排。LCD 禁放区对象本身未出现在输入快照中，必须另做 region/封装绑定回读。

## 差异、风险与修法

### A. CN1 rendered bbox 超出上边 1.162 mil，但 anchor 又必须保持 y=42 mm

- 名义板框上边为 1968.504 mil；CN1 `bbox.maxY=1969.666 mil`，超出 1.162 mil（0.0295 mm）。
- CN1 anchor y=1653.543 mil 与题面 42 mm 精确一致，旋转 180°也正确。微移 y 会直接破坏题面硬约束。
- 这个 1.162 mil 很像封装外形线宽的渲染半宽，不一定是物理本体真越界；仅凭 component bbox 无法证明。
- 修法：读 CN1 封装中外形/丝印图元的中心线坐标与线宽。若中心线正好落在板边，记录为描边 bbox 例外，不移动 anchor；若真实外形中心线也越界，保留冲突证据，调整封装线条，不改题面 y。

### B. LED1 不符合“摆放在板边”的直接题面要求

- LED1 最近板边是底边，`bbox.minY=546.570 mil`，即离板边 13.88 mm。这是板内区，不是板边带。
- 它与 USB1 的“近”关系成立，但不能代替“LED1 自身在板边”。
- 修法：将 LED1 移到 USB1 左侧或右侧的底边，使外形与底边保留制造/装配间隙，再将 U1/R3/C1/C2 收紧在内侧，同时保留 USB 插拔走廊和 U3 禁放边界。

### C. 按键等距通过，但“在板边”有视觉评审风险

- 三个按键下边都是 y=275 mil，离底边 6.99 mm。SW3 同时离右边 50.397 mil（1.28 mm），但 SW1/SW2 并不靠右边。
- 原题未给数值阈值，所以这不能像重叠那样直接判硬失败；但考试人工评审可能认为按键排偏内。
- 修法：保持 475 mil 间距，先向左平移整排以让 SW3 避开 SCREW4，再整组下移；R7/R8/R9/C8 随各自按键作刚体重排。最终以 M3 孔、按压可达性和完整 bbox 为准，不只移中心点。

### D. LCD/CARD 当前无器件重叠，但 LCD 封装禁放区本身未被证明

- U3 与最近其他器件的 bbox 正间隙：C7 19.376 mil，R6 21.566 mil；没有任何 bbox 相交。
- CARD1 与最近器件的 bbox 正间隙：C18 25.518 mil，R9 26.502 mil；没有任何 bbox 相交。
- CARD1 因题面固定坐标而距右边仅 5.085 mil，但仍在名义板框中；它处在右边直线段，不碰 R3 圆角。
- 修法：必须单独回读 U3 所绑 footprint 的 `component-keepout` region 实体、范围和实例绑定。仅有“当前没人放进去”不能代替题面要求的封装级禁放区。

### E. 接口朝向基本正确，CAN ESD 还应横向对齐信号脚

- USB1 在底边，外壳 bbox 到底边 49.135 mil，信号 pad 在更内侧 y=343.5 mil；旋转 0°与接口向下/板外一致。
- CN1 旋转 180°，pad 排在 y=1653.5 mil，壳体向上边延伸，与向上/板外一致。
- H1 `bbox.maxY=1865 mil`，离上边 103.504 mil（2.63 mm），可视为板边带；题面未对直排针要求开口旋转。
- D1 虽然与 CN1 外形 bbox 仅隔 19.175 mil，但 D1 放在 CN1 的 GND/CANH 一侧；D1-CANH 到 CN1-CANH pad 约 217 mil，D1-CANL 到 CN1-CANL pad 约 295 mil，保护支路偏长。
- 修法：将 D1 横向移到 CN1 的 CANH/CANL 两个 pad 正下方，使两个保护支路短且近似对称；R12 保持横跨 CANH/CANL，但不要挤占 ESD 到端子的最短通道。

### F. MCU 三个去耦与电源脚一一对应成立，其他芯片仍有偏远电容

以电容的电源 pad 到同区核心的相应电源 pad 中心距计算：

| 核心/电容 | 最近对应电源 pad 距离 | 判定 |
|---|---:|---|
| U6-C14 / C15 / C16 | 77.9 / 123.0 / 50.4 mil | 三个 +3V3 脚各有一只，均在两层板 150 mil 上限内；C15 仍可压缩 |
| U1-C2 | 180.9 mil | 偏远；C1 到 LED1 为 115.0 mil，可保留给 LED1，把 C2 收近 U1 |
| U4-C9 / C10 | 217.9 / 85.2 mil | C9 偏远，应对应 U4 的另一个电源脚重排 |
| U5-C12 / C13 | 125.2 / 188.7 mil | C13（100nF）偏远；应让小电容更近 U5.3，大电容位于电源来向 |
| CARD1-C18 / C19 | 295.7 / 375.3 mil | 两只都偏远，且小电容更远；移到 CARD1 pad4 左侧，按 `电源→C18→C19→pad4` 排列 |
| U3-C7 | 504.1 mil | 明显偏远；但 LCD 封装禁放区+全顶层限制会阻止直接贴脚 |
| U2 输入 C3/C4 | 229.2 / 91.3 mil | `USB来向→C3→C4→VIN` 的大后小顺序正确，C4 已贴脚，C3 是 bulk；需由实际铜路证明流向 |
| U2 输出 C5/C6 | 206.4 / 302.6 mil | 几何顺序为 `VOUT/TAB→C5→C6`，但 pad 距离偏大；旋转电容使 +3V3 pad 朝 U2，再压紧链路 |

C7 的修法建议：把 C7 放到 U3 左侧、与 U3 电源 pad 同 y，旋转到 +3V3 pad 朝向 U3，并与 LCD 禁放边界保持 12–20 mil。这可将距离由约 504 mil 降到约 180–230 mil；由于题面禁止其他顶层器件进入整个屏幕外形，如仍无法达到 150 mil，应把它记为题面/封装几何冲突，不可把 C7 放进禁放区来换取距离数字。

### G. 晶振到 MCU 的两线距离合格，但 200 mil 守护区被大量其他器件侵入

- U6 OSC_IN 到 X1 OSC_IN pad 为 99.8 mil，OSC_OUT 到 OSC_OUT pad 为 151.7 mil；晶振靠 MCU，且 X1 最近板边距离约 724 mil（18.4 mm），不在板边。
- C20/C21 到各自 X1 信号 pad 为 99.6/119.3 mil，两腿差 19.7 mil，负载电容的近与对称关系通过。
- 但 X1 bbox 外扩 200 mil 内，除 U6/C20/C21 外还有 C5、C6、C10、C14、C15、R3、R4、R13、R14、U2、U4。其中 U4/C10 距 X1 bbox 仅约 70 mil，C14/C15 仅 26/28 mil；U6 与 X1 本体 bbox 仅隔 8.447 mil。
- 这不违反原题的明文数值（题面没有给守护环尺寸），但不符合本 Skill 的晶振样例、也会挤压晶振顶层短直走线和包地净空。
- 修法：保留 X1/C20/C21 在 U6 下侧，先把 U4/C10 向 USB1 方向收紧；C14/C15 改放 U6 左上/右上侧且保持对应电源 pad 距离不超 150 mil；R13/R14 沿各自 MCU 信号脚移到侧面。X1 本体可向下微移 10–20 mil，使装配间隙达到至少 12 mil，再保留两条振荡线的无过孔直连通道。

### H. 有 7 组器件 bbox 间隙小于 12 mil，应在布线前做装配合法化

严格小于 12 mil 的组合为：C14-U6 6.282，C16-U6 6.376，C15-U6 7.974，C9-R1 8.038，U6-X1 8.447，C3-C4 9.968，C4-U2 10.047 mil。R3-R4 为 11.984 mil，可视为小数舍入后的 12 mil。

这些都没有重叠，所以不是题面的“器件重叠即 0 分”。但它们低于样例布局的常用 12 mil 装配间隙，也可能挡住窄焊盘出线。修法是在不破坏去耦引脚对应关系的前提下增加到 12–20 mil，优先处理 U6-X1、C9-R1 和 LDO 两组；QFN 周边三只去耦要同时保留所属电源 pad 的短通道。

## 建议的修改顺序

1. 先只读回读 CN1 封装外形中心线和 U3 封装级 `component-keepout` region，消除两个快照覆盖缺口。
2. 将 LED1 及 RGB 外围放到 USB1 旁的真正板边；保持光敏组在对侧。
3. 整理 U6 四周：保留 C14/C15/C16 逐脚去耦，为 X1/C20/C21 清出顶层短直通道和守护空间。
4. 重排 C2、C9、C13、C18/C19、C7，使小去耦电容靠相应电源 pad；同时压紧 LDO 输出链。
5. 将 D1 对齐 CN1 的 CANH/CANL 脚，保留 R12 横跨拓扑和顶层 CAN 直通通道。
6. 最后处理按键板边视觉风险与 <12 mil 装配间隙，再重新计算 69 件板内、重叠、LCD/CARD 禁放和实际引脚距离。

## 独立复测必需的回读

修改后的复测不应只重看 component list，至少要同一重载批次包含：

- `pcb list --include-bbox --include-pads`：69 件、TOP、固定 anchor/锁、两两重叠、引脚距离。
- `pcb outline-get`：真圆角 points/中心线，用它重做板内判定。
- `pcb region list` + U3 所绑 footprint 回读：禁放类型是“元件”，并且与 LCD 轮廓一致。
- 局部丝印/封装图元：判定 CN1 1.162 mil 是真越界还是描边渲染。
- 布线后的 track/via/pour 回读：验证电源先经电容、LDO 顶层 GND 回流、晶振/USB/CAN/PA9–PA14 顶层无换层。
